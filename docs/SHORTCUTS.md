# Oryn keyboard shortcuts

On macOS, Ctrl in this table means Cmd unless a row says otherwise. Every command is also in the command palette (Ctrl+P), which shows its shortcut.

| Key | Action |
| --- | --- |
| Up, Down, Page Up, Page Down, Home, End | Move the cursor |
| Left, Right | Move in grid view; step between columns in column view |
| Enter, double-click | Open a folder |
| Backspace, Alt+Up | Parent folder |
| Alt+Left, Alt+Right | Back, forward |
| Space, Insert | Mark or unmark, then move down |
| Ctrl+A (Cmd+A on macOS) | Mark or unmark all |
| Alt+S, Alt+D | Select or deselect by mask, such as `*.png` |
| Alt+I | Invert the selection |
| Alt+A | Clear the selection |
| Alt+E | Select every file with the cursor's extension |
| Ctrl+1, Ctrl+2, Ctrl+3 (Cmd on macOS) | List, grid or column view |
| Ctrl+T, Ctrl+W (Cmd on macOS) | New tab, close tab |
| Ctrl+Tab, Ctrl+Shift+Tab | Next tab, previous tab |
| Tab | Switch pane |
| Ctrl+F (Cmd+F) | Filter the active pane |
| Ctrl+\\ (Cmd+\\) | Dual or single pane |
| Ctrl+B (Cmd+B) | Show or hide the sidebar |
| Ctrl+\` or F9 | Toggle the terminal; it moves to the active pane's folder when opened |
| F2 | Rename |
| F5, F6 | Copy or move to the other pane |
| Shift+F5 | Duplicate |
| F7, Shift+F7 | New folder, new file |
| F8, Delete | Move to Trash |
| Shift+F8, Shift+Delete | Delete permanently |
| Ctrl+M (Cmd+M) | Batch rename |
| Ctrl+Shift+C (Cmd+Alt+C) | Copy the path |
| Shift+F10, right-click | Context menu |
| Ctrl+R (Cmd+R) | Refresh both panes |
| Ctrl+P (Cmd+P) | Command palette; type a path such as `~/Downloads` to jump |
| Ctrl+, (Cmd+,) | Settings |
| F3, Ctrl+Y (Cmd+Y), Preview button | Quick View: code, Markdown, images, office documents, hex; arrows step through files, Tab toggles hex |
| Ctrl+Shift+F | Search by name or contents |
| Ctrl+Shift+H | Find and replace in files |
| Ctrl+Shift+G | Git: stage, commit, diff, branches, pull and push |
| Ctrl+Shift+D | Compare and sync two folders |
| Ctrl+Shift+U | Find duplicate files |
| Ctrl+Shift+K | SHA-256 and SHA-512 checksums |
| Ctrl+Shift+S | Disk space |
| Ctrl+Shift+R | SFTP |
| Click a sidebar tag | Tag the selection and list tagged files |
| Context menu, Compress to ZIP | Pack the selection into a `.zip` next to it |
| Context menu, Extract Here | Unpack a `.zip`, `.tar` or `.tar.gz` into a new folder |
| Drag, Shift+drag | Copy or move onto a folder or the other pane |
| Ctrl+Q (Cmd+Q) | Quit |
